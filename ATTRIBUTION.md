# Contributions and attribution

Daniel Kral supervised the thesis and provided the starting code for the
experiments. The thesis contributions comprise the interventions, experimental
runs, and analysis presented here.

The repeated exchange game and human benchmark come from **Timm Teubner and
Sonia Camacho (2023)**. The memory–reflection–planning design draws on
**Park and colleagues (2023)**. See [references](docs/REFERENCES.md) for the
papers and how they inform this study.

## Public code and results

The Python scripts in this repository were written for this repository. They
plot aggregate results, compare means, illustrate the MRP schedule, and check
those calculations. The schedule example explains the timing; it is not the
code that ran the experiments.

The tables contain selected aggregate thesis results and human benchmark
values. The experimental code, original prompts, participant records, model
transcripts, and thesis manuscript remain in the private research archive.

This repository does not grant permission to redistribute code from the
private archive. Its citation identifies this repository and does not claim
authorship of the game, human data, or architectural ideas it references.
